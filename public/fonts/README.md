Self-hosted fonts for the intro page (both SIL Open Font License 1.1, from Google Fonts, Latin subset):

- `bowlby-one.woff2`: Bowlby One, the display font (AETERNA, OBJECTIVES, LEFT BEHIND).
- `montserrat.woff2`: Montserrat variable font, weights 400 to 800 (headings and body).

To swap the display font, replace `bowlby-one.woff2` with another .woff2 (keep the file name), or change
`--font-display` at the top of `src/ui/intro/intro.css`.
